### Engineering philosophy

Data infrastructure should not rely on black-box assumptions. The reliable version requires deterministic query plan lifecycles, clear execution boundaries, resilient distributed caching, and systems that maintain strict separation between compilation, optimization, and state mutation. That is the layer I care about engineering.
